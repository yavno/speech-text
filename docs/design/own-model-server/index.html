Your own model server

A third place beside On this Mac and Online service: a model the user already runs, on this Mac or elsewhere, reached at an address they write. Speech to text and AI Rewrite each have their own address, key and model. The review bar switches the role, the state the test request ends in, what kind of address it is, and the user's languages. The same form is drawn in Settings and in setup.

Settings

Picking the card shows the form under it; nothing is used until a test has passed once, so a half-typed address never takes over dictation. The card says In use like the others.

The rules
  • Third place, not a service in a list. It is neither built in nor a company with an account, and where the words go is the user's to say, so it gets its own card with its own sentence about privacy.
  • Presets fill the address, never more. Ollama, LM Studio, llama.cpp and Speaches are shortcuts to their documented default address; the user still tests. A preset for a server that cannot do the role is not shown (LM Studio under Speech to text).
  • Say where it goes. Under the address: This Mac, Your network or The internet, read off the address. Plain HTTP anywhere but this Mac gets a warning, and a key typed for it a second one.
  • Every failure in words, with the next step. The test sends a fixed sentence or a one-second silent WAV, never the user's words, and its result line stays until the address or model changes.
  • The model comes from the server. A picker of what /v1/models lists; a text field only when it lists nothing.
  • The other role's address is offered, once, above an empty address field; it is not copied silently.
  • More than one language: none is sent (as for every engine), and the speech form says that some servers then assume English.
